Linear Gradient

A linear gradient creates a smooth transition between two or more colors along a straight line.

CSS Property: background-image: linear-gradient()

Radial Gradient

A radial gradient creates a smooth transition between colors that spread outward from a center.

CSS Property: background-image: radial-gradient()
